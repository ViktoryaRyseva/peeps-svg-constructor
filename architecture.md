# Архитектура приложения

Актуально на 19 октября 2026 года после D-02/09/13. История этапов — в `docs/`; текущие правила имеют приоритет над прежними отчётами об IndexedDB.

## Стек и границы

React + TypeScript + Vite, CSS Modules, Zustand; нативный SVG DOM, DOMParser/XMLSerializer, Paper и svg-pathdata для анализа. Серверные операции — Node.js `fs` и локальный API, подключённый к Vite dev/preview. Авторизации и пользователей в MVP нет: одна библиотека для проекта. Dexie остаётся для переноса прежних данных и отдельных регрессионных проверок.

| Модуль | Ответственность |
| --- | --- |
| `src/App.tsx`, `src/components/` | Документы, диалоги, библиотеки, SVG-холст, рамки, лоадеры; без прямой записи на диск |
| `src/store/` | Состояние библиотек и редактора; обновление после подтверждённой записи |
| `src/services/storage.ts` | FileStorageService для API; прежний StorageService для миграции IndexedDB и изолированных тестов |

| `src/svg/` | Парсинг статического подмножества, топология, виртуальные детали, ресурсы, извлечение; без зависимости от хранилища |

## Хранение и запись

Рабочее хранилище — `project-files/` в корне проекта. `sources/` и `components/` содержат SVG, `compositions/` — JSON с автономными SVG экземпляров. `library.json` связывает имена/ID с файлами. Имена файлов на диске — UUID: пользовательское имя не превращается в путь. Подробный контракт — в [data-model.md](data-model.md).

Браузер обращается к `/api/project-library`. Оба штатных запуска, `npm run dev` и `npm run preview`, подключают API; простая раздача статического dist его не заменяет. Запросы идут на локальный сервер этого проекта. Прямую раздачу папки данных через dev-сервер запрещает `server.fs.deny`.

Операция изменения получает файловую блокировку, читает актуальный каталог, проверяет уникальность имени и ожидаемую ревизию, пишет новый файл записи, затем атомарно заменяет каталог через rename. Старая версия файла остаётся на диске. Поэтому неудача до смены каталога не заменяет доступный предыдущий проект. Параллельные процессы используют ту же блокировку; после аварии блокировка освобождается, если процесс-владелец уже не существует. Это защита обычной записи и сбоя процесса; fsync/гарантии при физическом отключении питания не заявляются.

UI меняет библиотеку и снимает dirty только после успешного ответа API. Ошибка оставляет диалог и черновик, действие можно повторить. Молчаливого переключения на IndexedDB при недоступном API нет. Конфликт updatedAt преобразуется в CompositionConflictError; можно сохранить отдельную копию.

При первом запуске переносятся найденные записи прежней IndexedDB; если их нет и файловый каталог ещё не создан, добавляются три предоставленных исходника, три компонента-персонажа и «Три характера». Повторный запуск не восстанавливает удалённые образцы. Старую базу не очищаем. Отпечаток перенесённого набора хранится в каталоге и предотвращает повторный импорт. Конфликтующие данные сохраняются отдельными копиями с именами «импорт N», ссылки компонентов переназначаются, автономные SVG снимки сохраняются.

Библиотека доступна после перезагрузки, очистки данных сайта и из другого браузера при обращении к тому же серверу и папке. При переносе проекта нужно переносить весь `project-files/`; папка не включается в Git. Автосохранения несохранённого черновика нет.

## Состояние редактора

Персистентные данные — SVG-записи и проекты schemaVersion 1. URL превью, DOM, SelectionModel/Paper, выделение, раскрытые папки, масштаб и диалоги в них не входят. Композиции содержат собственные SVG: удаление компонента не повреждает сохранённый проект.

Baseline — массив снимков значимых полей экземпляров с общими ссылками на неизменяемые строки SVG. Dirty-check сравнивает поля и порядок массива без JSON-сериализации на каждом движении. Точный возврат к baseline снимает dirty; выделение, zoom и URL превью не влияют на него.

## SVG и взаимодействие

Загрузка проверяет XML, namespace, статический автономный векторный состав, отсутствие исполняемого содержимого, CSS-анимаций/переходов и внешних ресурсов. SVG сохраняется исходным текстом. Структурная диагностика отдельно предупреждает о конструкциях, не поддерживаемых выделением: файл можно сохранить как «Только просмотр». Геометрические ограничения выбранных деталей могут выявиться позднее с понятной ошибкой.

SourceCanvas загружается через React.lazy и монтирует SVG в изолированный Shadow DOM. Клик — ближайшая группа, двойной клик — мелкая деталь, Shift + клик — добавить/исключить деталь; Esc снимает выбор. Alt не используется. Исходные строки и рисунок не переписываются. Обработчик создаёт временную копию, фиксирует ресурсы относительно исходных bbox, извлекает выбранное, изолирует ID и возвращает автономный SVG. Временный DOM удаляется и при ошибке.

Поддержаны вложенные SVG с конечным viewBox и числовыми x/y/width/height. Координаты измеряются через getScreenCTM относительно корня, поэтому учитываются все viewport и внешние трансформации. Вложенные области остаются в SVG, сохраняя обрезание и координаты ресурсов. Для вложенных областей с процентными/относительными размерами сохраняется явный отказ. Transform-origin по-прежнему требует предварительной нормализации.

Собственный экспорт — стандартный SVG 1200 × 800, прозрачный фон, группы/пути/defs и вложенные viewport компонентов. Он загружается как исходник, допускает выделение/сохранение детали и повторный экспорт. Частичный выход экземпляра за корневой холст переносится с явным clipPath. Скачанный SVG содержит рисунок; редактируемый проект со всеми экземплярами сохраняется отдельно как JSON на диске.

## Композиция и геометрия

x/y — верхний левый угол масштабированной рамки до поворота; вращение относительно её центра. Размеры берутся из viewBox, либо width/height, для старых неопределённых размеров — fallback 250 × 450. Угловые маркеры сохраняют текущие пропорции и противоположный угол, боковые — вторую ось и противоположный край. Размер при resize не меньше 0,01; отражения нет. Escape/pointercancel отменяют жест.

Перед изменением, открытием и сохранением проверяется конечность геометрии; координаты/размеры ограничены 1 000 000, угол — 1 000 000 000°. Новые экземпляры размещаются повторяющимися рядами с видимой частью на холсте. Полностью ушедшие объекты возвращаются в центр кнопкой, сохраняя размеры, угол, SVG и слои. Частичный выход разрешён.

## Лоадеры

Есть индикаторы начального чтения библиотеки, загрузки/проверки файлов, подготовки исходника, извлечения компонента, сохранения и экспорта. Перед тяжёлой синхронной работой React успевает показать индикатор, браузер — нарисовать кадр. Отложенная подготовка исходника отменяется при закрытии; повторные операции защищены синхронным ref-флагом. CSS-анимация спиннера отключается при prefers-reduced-motion. Это не перенос анализа в Web Worker и не общий лимит сложности SVG.
