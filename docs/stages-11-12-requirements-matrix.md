## Правила вне нумерованных ID

| Правило | Оценка |
| --- | --- |
| Пустое состояние, исходник, композиция; панели по режимам | Реализовано и проверено |
| Guard «Сохранить / Не сохранять / Отмена» при смене работы | Работает для подтверждённых изменений; незавершённый текстовый ввод отдельно D-12 |
| Загрузка/экспорт поверх текущей работы | Подтверждено; активный документ и dirty сохраняются |
| Неподдерживаемое SVG отклонять понятно, без испорченного результата | Частично: D-01 выдаёт неправильный результат без отказа; D-04/D-06 дают технически неполную диагностику |
| Нужные defs/стили, уникальные ID, собственный viewBox | Штатные проверки проходят; Unicode URI и процентный центр поворота требуют исправления |
| Сохранение JSON и SVG — разные процессы | Разделены; экспорт не обновляет baseline |
| Локальное хранение без серверной части | Соответствует MVP; ограничения сохранности и переноса D-13 |

Матрица не является отметкой «всё принято». Окончательный статус этапа 12 остаётся открытым до устранения выбранных замечаний и подготовки материалов сдачи.
