# Итоговая перепроверка проблем 1–19

19 октября 2026 года. Проверено текущее приложение после файлового хранения, повторного импорта SVG, тёмно-синего оформления и повышения контрастности правой панели. Номера соответствуют D-01–D-19 [исходного аудита](audit-stages-11-12.md), а не этапам разработки.

В этой проверке код приложения и правила работы не менялись. Созданы отчёт и новые артефакты. Отложенные пункты не выполнялись и не объявляются исправленными.

## Статус всех пунктов

| № | Проблема | Текущий статус и остаток |
| --- | --- | --- |
| **1** | Пустой/неверный компонент при transform-origin | **Риск молчаливого повреждения устранён.** Такой исходник заранее помечается «Только просмотр», сохранение детали недоступно. Полная поддержка transform-origin не добавлена; нужна предварительная нормализация поворота в матрицу. Это безопасный отказ, а не полноценная поддержка конструкции. |
| **2** | Тяжёлые SVG блокируют интерфейс | **Частично. Лоадеры готовы.** Они появляются до подготовки/извлечения, работают при загрузке и сохранении; отложенная подготовка отменяется при уходе. Но сам геометрический анализ остаётся синхронным, без Worker, общего бюджета сложности и отмены уже начавшегося расчёта. Поэтому тяжёлый файл всё ещё способен надолго занять основной поток. |
| **3** | Большие конечные числа дают NaN/Infinity | **Исправлено в проверенных сценариях.** Проверяются исходные и производные величины до изменения состояния/открытия/сохранения; технические пределы блокируют чрезмерные значения. Невалидная операция оставляет прежнюю геометрию. |
| **4** | Кириллические ID градиентов не разрешаются | **Исправлено.** URI-фрагмент декодируется один раз перед поиском DOM-ID. Проверены кириллица, emoji и буквальный процент; цветной компонент сохраняется, переживает перезагрузку и независимо отображается. |
| **5** | CSS-анимация проходит в статическую библиотеку | **Исправлено для покрытого статического подмножества.** Keyframes/animation/transition и запрещённые SMIL-конструкции отклоняются до сохранения/превью. Старые динамические записи не удаляются, их исполняемое превью блокируется. Это не универсальный аудит всех возможностей CSS/SVG. |
| **6** | Повреждённый path оставляет скрытый DOM | **Исправлено.** Исключение конструктора освобождает контейнер, ошибка контура понятна. Многократные неудачные подготовки и открытия не накапливают скрытые хосты. Повреждённая геометрия автоматически не восстанавливается. |
| **7** | Новые/перемещённые экземпляры теряются за холстом | **Исправлено для согласованного поведения.** Начальное размещение повторяется в видимых рядах; полностью ушедшие объекты возвращаются кнопкой без выделения, в том числе после сохранения/перезагрузки. Угол, масштаб, SVG и слои сохраняются. Выход за границы остаётся разрешённым; большое число элементов может перекрываться. |
| **8** | Загруженный SVG оказывается непригоден для выделения | **Ранняя диагностика готова; ограничение SVG остаётся.** Структурно неподдерживаемый статический файл помечается заранее и открывается для просмотра с причиной отказа. Проверка не доказывает корректность всей геометрии: повреждённый path или ограничение ресурса могут выявиться позднее. Text/use/фильтры и относительные вложенные viewport не стали полностью поддерживаемыми. |
| **9** | Приложение не читает собственный SVG-экспорт | **Исправлено в проверенном формате экспорта приложения.** Настоящий download → загрузка → выделение детали → сохранение компонента → повторный экспорт проходит. Проверены вложенные трансформации, ненулевой viewBox, градиент/маска/clipPath и корневое обрезание. SVG открывается как рисунок для извлечения; полная структура экземпляров проекта хранится отдельно в JSON. |
| **10** | Полные SVG сериализуются при каждом движении | **Исправлено.** Dirty-check сравнивает поля и порядок экземпляров без повторной JSON-сериализации SVG. Точный возврат к сохранённым значениям снимает dirty; выделение и zoom его не меняют. Это не подтверждение неограниченной производительности всей сцены. |
| **11** | Противоположный видимый маркер маленькой рамки смещается | **Оставлено по решению пользователя.** Минимальная видимая рамка 32 px сохранена. Для меньшей геометрии она отличается от реальной рамки объекта; прежнее наблюдение не объявляется технически исправленным и не блокирует приёмку в принятом варианте. |
| **12** | Незавершённый числовой ввод теряется при перезагрузке | **Осталось, повторно воспроизведено.** Поля действительно есть при выделении экземпляра композиции. До Enter/ухода из поля число не попадает в рабочую модель, не включает dirty и может пропасть без предупреждения. Подтверждённый ввод фиксируется штатно. |
| **13** | Данные зависят от браузерной базы, нет файлов проекта | **Согласованное файловое хранение готово.** SVG/JSON и каталог находятся в project-files; проверены новый браузер, ошибка записи/повтор, конфликт вкладок, перенос IndexedDB и перезапуск собранного приложения. Автоматического резервирования и очистки старых версий нет; для резервной копии нужно сохранять весь каталог. Несохранённый черновик не автосохраняется. |
| **14** | В стартовой библиотеке 3 SVG вместо 20 | **Отложено, не готово для полной сдачи.** В материалах и public/demo по-прежнему три подготовленных Peep. Остальные 17 из согласованного набора пока не предоставлены/не добавлены. Пользовательские загрузки не считаются проверенной стартовой библиотекой из 20 иллюстраций одного стиля. |
| **15** | Редактируемость в стороннем редакторе не проверена | **Отложено, не подтверждено.** Векторность и независимый браузерный рендер проверены; импорт/редактирование/сохранение в выбранном внешнем редакторе этим не доказаны. Поддержка конкретного редактора не заявляется. |
| **16** | Нет полной приёмки других браузеров и длительной работы | **Отложено, не подтверждено.** Текущие автоматические проверки используют установленный Chrome, включая узкие экраны. Это не проверка Safari/Firefox и не многочасовой тест удержания памяти/нагрузки. |
| **17** | Исходники не оформлены в Git | **Отложено, не готово.** git ls-files по-прежнему возвращает только README.md; исходники, конфигурация и тесты остаются untracked. Работающая локальная папка и сборка не равны готовому репозиторию, который можно клонировать и запустить. |
| **18** | Не собран финальный демонстрационный комплект | **Отложено, не готово.** Есть инструкции, многочисленные отчёты, снимки и автоматический сквозной сценарий. Но нет оформленного итогового комплекта: выбранных 2–3 демонстрационных примеров, короткой демонстрации и сводки использованных AI-инструментов для передачи. |
| **19** | README противоречит приложению/сборке | **Основная часть исправлена, осталась небольшая неточность.** Вход в редактор, отсутствие лабораторных страниц, Node API, project-files и повторный импорт описаны. Но последняя фраза README «База данных и SVG-снимки не мигрируются и не очищаются» неоднозначна на фоне автоматического переноса IndexedDB в файлы. Следует уточнить, что прежняя база не очищается и её схема не мигрируется, а записи переносятся. Сейчас документ не полностью непротиворечив. |

## Что важно для готовности

Для локального MVP основной проверяемый сценарий реализован: исходник → деталь → библиотека → композиция → сохранение/повторное открытие → SVG → повторный импорт. В покрытых сценариях проверок приложение не показало нового фатального отказа. Это не заключение о полной поддержке SVG или безопасности публичного сервиса.

Оставшиеся технические задачи исходного списка — **2** (устойчивость к общей сложности), **12** (неподтверждённый ввод) и небольшое уточнение **19**. В **1/8** остаются явные, документированные границы поддержки; они не скрываются под статусом «все SVG работают». **11** принят пользователем, **14–18** отложены и остаются условиями полной финальной сдачи.

Файловая библиотека требует запущенного Node API (`npm run dev` или `npm run preview`). Простая статическая раздача dist через MAMP не заменяет API. Это текущий способ запуска, а не поломка экспорта. Пользователей и авторизации по согласованному MVP нет.

## Дополнительная проверка пункта 12

В изолированном Chrome открыт сохранённый проект, выделен экземпляр. В X введено 777 без Enter и без ухода из поля:

- поле показывает 777;
- рабочая модель всё ещё содержит X = 160;
- «Сохранить» остаётся недоступной;
- при обновлении страницы предупреждения нет;
- повторно открытый сохранённый проект содержит X = 160.

После ввода 888 и Enter модель содержит 888, сохранение доступно. Таким образом, ограничение относится именно к неподтверждённому вводу. Фактические значения и отсутствие JS-ошибок: [extra-observations.json](final-audit-artifacts/extra-observations.json).
